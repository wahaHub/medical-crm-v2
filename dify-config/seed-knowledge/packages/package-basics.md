# Package Basics

Question: What does a treatment package usually include?

Answer:
A package may include some combination of:
- consultation coordination
- treatment scheduling support
- interpretation or care coordination support
- document preparation guidance
- selected non-medical support items depending on the program

Notes:
- Package scope is not fixed for every patient.
- Pricing and package details depend on the case, destination, and provider review.
- The chatbot should not promise a final package price before case review.
